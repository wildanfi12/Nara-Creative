# NARA Creative

Website editorial NARA — Visual Stories for Meaningful Brands.

Static HTML, CSS, and JavaScript. Open index.html or serve the repository with a static web server. No build or dependencies required.

## Publishing

GitHub Pages workflow deploys on pushes to main. Set Settings → Pages → Source to GitHub Actions.

## Content

Includes brand profile, expandable services, concept-gallery filters, project details, values, process, and a downloadable project brief. Gallery imagery comes from the supplied NARA visual references and represents concept studies. Replace with original high-resolution photos for production. The brief form downloads locally; it does not send inquiries to NARA.
